# Techno hisoblovchi

Saytni ochish uchun `index.html` faylini ikki marta bosing. Internet yoki qo‘shimcha dastur o‘rnatish kerak emas.

- Qovurg‘ali radiator: seksiya × 0.21
- Panel radiator: metr × 2.5
- Issiq pol: m² × 0.25
- Umumiy quvvat va 25, 35, 50, 75, 100, 200 kW orasidan mos kotyol avtomatik hisoblanadi.

Saytni hostingga joylash uchun shu papkadagi `index.html`, `style.css`, `calculator.js` va `logo.png` fayllarini birga yuklang.
